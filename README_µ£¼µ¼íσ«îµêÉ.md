# MaiMemoUI 本次功能更新

本次继续在现有 Java Android 项目上开发，不依赖 C#、Python 或 HTTP 后端。

## 本次修改

### 1. 修复设置项点击无反应
- 设置行显式设为可点击、可聚焦。
- 学习计划、记忆模式、复习模式、发音口音、提醒时间均绑定点击事件。
- 开关行点击整行也可以切换开关。
- 修复开关点击事件冒泡：开关控件自身消费点击事件，点击深色模式不再触发行级第二次切换，其他开关状态各自独立保存。
- “保存设置”按钮有明确的本地保存提示；设置值会自动持久化。

### 2. 本地设置
- 每日学习量、每日复习上限、词上限。
- 学习顺序、记忆模式、复习模式、发音口音。
- 提醒时间、自动发音、例句、音标、每日提醒、消息通知。
- 深色模式现在会实际切换主题；增加了夜间配色资源。
- 账号设置增加本地昵称编辑、主题切换、隐私说明和缓存清理。

### 3. SQLite 词库接入
- 将内置 `inami.db` 移到 `app/src/main/assets/inami.db`。
- 首次使用时复制到 App 私有数据库目录 `databases/inami.db`。
- 新增 `LocalDatabase` 统一管理数据库打开和本地状态表。
- 新增 `WordRepository` 统一读取词书、查词、保存学习状态、生词本和收藏。
- 原始内置词库只作为初始数据库，不再直接从 Java 源码目录读取。

### 4. 词书、生词本、收藏
- “我的词书”从 SQLite 的 `Count` 表读取词书和总词量。
- 已学数量与进度来自本地学习记录。
- 选择词书后可以开始学习。
- 生词本和收藏使用本地表保存，点击单词可查看释义并移出列表。

### 5. 本地背词流程
- 新增 `StudyActivity`。
- 从当前词书读取尚未学习的单词。
- 可以显示释义、例句和音标（受设置控制）。
- “再复习”和“认识”会写入学习状态与学习日志。
- 新增简化间隔重复排程：根据记忆结果和复习次数设置下次到期时间；到期词优先进入复习，复习上限和新词上限分别计算。
- 支持加入/移出生词本、收藏/取消收藏。
- 遵守“每日学习量”和“每日复习上限”设置。

### 6. 首页和统计
- 首页查词框可以搜索本地词库的英文单词、中文释义和日语词条。
- 查词结果可以查看释义、加入生词本或收藏。
- 首页日历与今日学习数量读取本地学习日志，不再生成随机演示数据。
- 连续打卡数根据本地学习日志计算。
- 学习统计页的近 7 天柱状图和今日摘要改为本地学习数据。
- “去复习”入口会进入本地学习页面。

## 数据位置

- 内置初始词库：`app/src/main/assets/inami.db`
- 安装后的可写数据库：Android App 私有 `databases/inami.db`
- 设置：App 私有 SharedPreferences
- 学习状态、学习日志、生词本和收藏：安装后的 `inami.db` 中的 `app_*` 表

## 本次新增：可替换的单词推送接口与 FSRS-6 数据记录

- UI 通过 `business/wordpush/WordPushService` 获取单词，不再直接绑定推送选择逻辑。
- `WordDeliveryProvider` 是可替换策略接口；默认实现 `FsrsWordDeliveryProvider` 采用“到期复习优先，其次新词”的策略。
- `WordPushService.nextItem()` 返回 `WordDeliveryItem`，包含单词、来源（到期复习/新词/自定义）、到期时间、稳定性、难度、当前可提取率、复习次数、遗忘次数、可用评分和 provider ID。后续可以替换 Provider，而不必改 StudyActivity 的数据入口。
- `Fsrs6Scheduler` 使用 FSRS-6 官方 21 个默认权重和 D/S/R、初始状态、成功回忆、遗忘、同日复习与可训练遗忘曲线公式。当前实现的是官方 FSRS-6 scheduler/inference，不包含基于用户历史训练 21 个权重的优化器。
- 评分值统一为 FSRS 官方等级：1=Again、2=Hard、3=Good、4=Easy。现有 UI 的“再复习”映射 Again，“认识”映射 Good；Provider 接口支持后续扩展 Hard/Easy。
- `app_word_state` 持久化每张卡的稳定性、难度、复习次数、遗忘次数、上次评分、上次经过天数、计划间隔、可提取率、到期时间和更新时间。
- `app_learning_log` 逐次保存评分、学习/复习类型、复习前后状态、经过天数、计划间隔、复习前可提取率和新到期时间，供统计页查询。SQLite 启动时使用 `PRAGMA table_info` 做增量迁移，不要求删除旧库。
- 官方算法参考：FSRS 算法说明 https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm；参考实现 https://github.com/open-spaced-repetition/fsrs-rs。
