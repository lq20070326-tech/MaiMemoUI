## 口径说明
- 累计学习：当前 `app_word_state` 中去重后的卡片数。
- 已掌握：稳定性至少 21 天且最近一次评分为 Good/Easy 的卡片数，是应用内的展示口径，不是官方 FSRS 字段。
- 连续学习：从今天（若今天尚未学习则从昨天）往前连续存在学习日志的自然日数。
- 学习时段：按学习日志时间分为晨间（00:00–11:59）、午间（12:00–17:59）、晚间（18:00–23:59）。
- 本周小结：按自然周（周一到周日）统计学习事件，并与上周比较。
- 统计均为本机数据库数据；清除应用数据会清空这些本地学习记录。

## 本次追加：词书排序、音频与导入
- 我的页“词书与单词本”显示本地 `Count` 表中的实际词书数量，包含用户导入的词书，不再固定显示 3 本。
- 统计页“词书学习进度”按每本词书已学习卡片数从高到低排列；数量相同则总词数较多的优先。
- 背词页面加入发音按钮；当本地 `Global.autoPlay` 为开启状态时，切换到新单词会自动播放有道词典 `dictvoice` 发音。MP3 缓存于应用私有缓存目录 `cache/Mp3Cache`，网络失败时可手动重试。首次下载需要网络连接。
- 词书页面增加“导入词书（CSV / TSV）”。支持 UTF-8 CSV/TSV，列顺序为 `word,meaning,phonetic,pos,sentence,sentence_cn`，单词列必填；可以有表头。CSV 逗号分隔，TSV 制表符分隔，字段内含分隔符请使用双引号。每个单词一行；当前导入器不支持字段内换行。导入会新建词书，不覆盖已有词书。
- 本次没有声称 Gradle 完整编译或真机验证成功；需在具备 Android Gradle 插件/依赖缓存的环境中构建并在设备上验证音频网络访问与导入文件选择器。
