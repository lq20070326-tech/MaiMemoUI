# FSRS 训练数据导出与参数导入

## 入口
“我的”页 → 功能宫格 → **FSRS数据与参数**。

## 导出训练 CSV
点击“导出 FSRS 训练数据 CSV”，选择手机上的保存位置。CSV 按复习时间升序，每一行对应一次本地学习/复习事件，包含：

- `id`, `book_name`, `word_rank`, `reviewed_at`
- `event_type`, `is_review`, `rating`, `result`
- `elapsed_days`, `scheduled_days`
- `stability_before`, `difficulty_before`, `retrievability_before`
- `stability_after`, `difficulty_after`, `due_at_after`

`rating` 为 FSRS 评分：1=Again，2=Hard，3=Good，4=Easy。旧版本产生的日志可能没有完整的历史字段（数据库默认值会显示为 0 或 1），导出不会伪造缺失数据。训练前请先检查并按拟合工具要求清洗数据。

## 导入拟合后的 w 参数
选择“导入拟合后的 w 参数 CSV”。必须有且仅有 21 个数值，依次对应 `w0` 到 `w20`。支持以下格式：

1. 单行：`0.212,1.2931,2.3065,...`（共 21 个数值）；
2. 多行：每行一个数值；
3. 多行两列：`w0,0.212`、`w1,1.2931`……；可包含表头。

参数必须是有限正数且不超过 100。导入后参数保存在应用本地，之后的新评分排程和记忆可提取度统计将使用这些参数。导入不会自动重排现有卡片的到期日期。点击“恢复默认 FSRS-6 参数”可回到内置默认值。

## 重要说明
该功能负责导出训练样本和加载外部拟合结果；**应用内尚未实现 w 参数优化/拟合器本身**。需要先使用支持 FSRS-6 的外部拟合程序对 CSV 进行拟合，再导入得到的 21 个参数。导出文件保存在用户选定的位置，不会自动上传。
